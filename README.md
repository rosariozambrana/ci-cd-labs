## Elaboración del Laboratorio 3

En este laboratorio se incorporan pruebas automatizadas al pipeline de CI/CD utilizando GitHub Actions.
- Se configuran pruebas unitarias automáticas como un Quality Gate (Filtro de Calidad).
- Si alguna prueba falla, el pipeline se detiene automáticamente bloqueando cambios defectuosos.
- Se publican y conservan los reportes de resultados de las pruebas como artefactos descargables.
